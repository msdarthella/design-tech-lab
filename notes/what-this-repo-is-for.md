# What this repository is for

This repository is a place to document my learning and experiments at the intersection of visual design, brand systems, digital production, and front-end implementation.

## What I want to explore

- How design systems support faster digital production
- How reusable templates can improve campaign consistency
- How accessibility and brand standards can work together
- How designers can better understand front-end implementation
- How tools like GitHub, Tailwind CSS, and documentation workflows can support design work

## How I plan to use it

I’ll use this space for notes, small experiments, workflow documentation, and examples that show how I think through digital design systems and production challenges.
